Une alternative gratuite à Punto Switcher

Vous cherchez à remplacer Punto Switcher ou Caramba Switcher ? AURA Switcher détecte le texte tapé dans la mauvaise disposition de clavier et le corrige automatiquement — gratuit, open source, sans publicité, rien n’est envoyé en ligne. Pour macOS et Windows.

Mac et Windows — les mêmes habitudes

macOS
  • Apple Silicon et Intel
  • Code de langue dans la barre des menus : EN, УК, FR…
  • macOS 13 et plus récent
⊞ Windows
  • x64 et ARM64, sans installation
  • Code de langue dans la zone de notification
  • Les mêmes touches que sur Mac

Prêt en une minute

Téléchargez

Décompressez l’archive. Sur Mac, glissez AURA dans Applications ; sur Windows, lancez AURA.exe.

Autorisez

Sur Mac : Réglages Système → Confidentialité et sécurité → Accessibilité → AURA.

Tapez

Le code de langue apparaît dans la barre des menus (Mac) ou la zone de notification (Windows). AURA s’occupe du reste.
