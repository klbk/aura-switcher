一分钟内轻松上手

下载

解压压缩包。在 Mac 上将 AURA 拖入“应用程序”文件夹，在 Windows 上直接运行 AURA.exe。

授权

Mac 端设置：系统设置 → 隐私与安全性 → 辅助功能 → 勾选 AURA。

打字

菜单栏（Mac）或系统托盘（Windows）会显示当前语言代码，剩下的交给 AURA 即可。

它安全吗？

安全透明

所有源代码均托管在 GitHub 上，任何人都可以审查代码。

为什么它需要键盘访问权限

仅用于识别你输入的文本并进行纠错。软件不会保存或向任何地方发送输入内容，且应用本身无需联网。

首次启动时提示安全警告是正常现象

测试版尚未购买昂贵的 Apple 或 Microsoft 开发者签名证书。Mac：点击“好” → 系统设置 → 隐私与安全性 → 点击“仍要打开”。Windows：点击“更多信息” → “仍要运行”。
