Жүктөңүз

Архивди ачыңыз. Mac’та AURA’ны «Колдонмолор» папкасына сүйрөңүз, Windows’то AURA.exe иштетиңиз.

Уруксат бериңиз

Mac’та: Тутум жөндөөлөрү → Купуялык жана коопсуздук → Атайын мүмкүнчүлүктөр, Input Monitoring → AURA.

Териңиз

Тил коду меню сапта (Mac) же эскертме аймагында (Windows) көрүнөт. Калганын AURA өзү жасайт.

Бул коопсузбу?

Ачык код

Бардык код GitHub сайтында: программа эмне кылаарын каалаган адам текшерип көрө алат.

Эмне үчүн клавиатурага мүмкүнчүлүк керек

Терилген сөздү көрүп, оңдоо үчүн. Текст сакталбайт жана эч жакка жөнөтүлбөйт, программага интернет керек эмес.

Биринчи жолу ачканда эскертүү чыгышы — кадимки көрүнүш

Бетанын Apple жана Microsoft акы төлөнүүчү кол тамгасы азырынча жок. Mac: «Бүттү» → Тутум жөндөөлөрү → Купуялык жана коопсуздук → «Баары бир ачуу». Windows: «Кеңири маалымат» → «Баары бир иштетүү».
