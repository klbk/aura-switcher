무료 Punto Switcher 대안

Punto Switcher나 Caramba Switcher를 대체할 프로그램을 찾고 있나요? AURA Switcher는 잘못된 자판으로 입력한 글을 알아채고 자동으로 고쳐 줍니다 — 무료, 오픈 소스, 광고 없음, 인터넷으로 아무것도 보내지 않습니다. macOS와 Windows용.

Mac과 Windows — 같은 습관

macOS
  • Apple Silicon 및 Intel
  • 메뉴 막대에 언어 코드: EN, KO…
  • macOS 13 이상
⊞ Windows
  • x64 및 ARM64, 설치 불필요
  • 트레이에 언어 코드
  • Mac과 같은 키

1분이면 준비 완료

다운로드

압축을 푸세요. Mac에서는 AURA를 응용 프로그램으로 끌어오고, Windows에서는 AURA.exe를 실행하세요.

허용

Mac: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → AURA.

입력

언어 코드가 메뉴 막대(Mac)나 트레이(Windows)에 나타납니다. 나머지는 AURA가 합니다.
